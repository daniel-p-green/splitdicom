# 01. Background: why "DICOM as code" does not shrink storage

Date: 2026-11-11

## The starting idea

Represent DICOM images as code (for example Python generated by pydicom's `codify`, or the DICOM JSON model) to save storage.

## Finding

It does not save space.

- Pixel data is nearly all of a scan's bytes. `codify` and JSON only re-express the metadata, usually in more bytes than the binary original.
- The pixels are measured sensor data that include noise. Noise cannot be predicted, so it cannot be regenerated exactly from a short program. Noise content sets the ceiling on any lossless method.

## What the standard already offers

- Lossless transfer syntaxes: JPEG-LS, JPEG 2000, HTJ2K (Supplement 235), JPEG XL (Supplement 232).
- AWS HealthImaging stores HTJ2K lossless by default.
- A 2000 benchmark of grayscale medical images reported an average lossless ratio of 3.81 for JPEG-LS and JPEG 2000. Our own CT measurements came in lower, at 2.8x to 3.5x (see note 02).

## Directions that could go further

Ranked by potential upside. None is validated for diagnostic use.

1. **Noise as code.** Store a denoised image plus a small noise model, then regenerate statistically matched noise on display. Video codecs do this (AV1 film grain synthesis). No clinical validation found for radiology.
2. **Scan as a function.** Fit a small neural network to one scan and store the weights. Papers report very high ratios. Learned priors can produce convincing detail that was never scanned, so this suits training data and previews, not primary diagnosis.
3. **Derived series as recipes.** Store thin slices once and keep thick slices and reformats as a recipe plus a lossless correction. Untested here. Size of the saving is unknown.
4. **Learned lossless.** Neural predictors beat standard codecs by modest margins (roughly 9% to 15% in the papers found).

Lossy compression for primary reading has precedent: the Canadian Association of Radiologists published standards for it in 2008.

## Working conclusion

The codec is not the scarce part. Evidence that a given method never changes a diagnosis is. That is why the later notes focus on measurement.
